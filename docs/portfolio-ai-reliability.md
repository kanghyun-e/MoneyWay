# MoneyWay Portfolio Metrics

## 12번 슬라이드용 실험 표

자동화된 AI 응답 변형 테스트 기준입니다. 실제 OpenAI를 30회 호출한 수치가 아니라, AI가 낼 수 있는 오류 응답을 mock으로 재현해 후처리 안정성을 검증한 결과입니다.

| 검증 항목 | 기준 | 결과 |
| --- | ---: | ---: |
| DB 외 장소 생성률 | 0% 목표 | 30개 변형 중 0건 |
| 필수 슬롯 누락률 | 0% 목표 | 30개 변형 중 0건 |
| 예산 초과율 | 0% 목표 | 30개 변형 중 0건 |
| JSON 파싱 성공률 | 100% 목표 | 정상 JSON 1/1 성공, 비JSON 1/1 차단 |
| 카테고리 불일치율 | 0% 목표 | 30개 변형 중 0건 |

## 슬라이드 문장

AI 응답을 그대로 저장하지 않고, DB 후보 제한, JSON 파싱 검증, 슬롯/카테고리/예산 후처리, Plan 저장 순서로 검증 파이프라인을 구성했습니다.

30개 AI 오류 응답 변형 테스트를 통해 DB 외 장소 생성, 예산 초과, 필수 슬롯 누락 여부를 검증하고 후처리 로직으로 결과 안정성을 보정했습니다.

숙소를 기준점으로 선정한 뒤, 반경 기반 후보 조회와 예산 비율 필터링을 적용해 AI 입력 후보를 현실 범위로 제한했습니다.

## 구현 규모 수치

| 항목 | 포트폴리오에 넣을 수 있는 수치 |
| --- | --- |
| 장소 후보 조회 | 숙소 1개 선선정, 관광지/식당/카페 후보를 `duration * 2 + 3`개씩 구성 |
| 거리 제한 | 숙소 기준 반경 10km부터 시작, 후보 부족 시 1.5배씩 확장, 최대 50km |
| 슬롯 검증 | 당일치기 5개 슬롯, 2일 이상 6개 슬롯 강제 |
| 카테고리 검증 | 오전/오후, 점심/저녁, 카페, 숙소 슬롯별 카테고리 보정 |
| 데이터 처리 | TourAPI 동기화, 엑셀 업로드, 중복 제거, 기존 장소 업데이트, 가격 정보 업데이트 |
| API 규모 | 컨트롤러 매핑 기준 REST API 48개 |
| 테스트 규모 | 자동화 테스트 10개 통과 |

## 테스트 근거

| 테스트 파일 | 검증 내용 |
| --- | --- |
| `AiPlanServiceTest` | 예산 입력 검증, 필수 슬롯 보정, 식당 슬롯 보정, DB 외 장소 제거, 예산 상한 보정, 30개 AI 응답 변형 회귀 테스트 |
| `AiPlanClientTest` | OpenAI 응답의 JSON 코드블록 추출 및 비JSON 응답 차단 |
| `PlaceRepositoryTest` | 관광지/식당/카페 반경 조회 쿼리의 Haversine 거리 필터 계약 검증 |
| `AdminDataServiceTest` | 엑셀 업로드 중복 제거 및 기존 식당 데이터 업데이트 검증 |

## 면접 답변용 한 문장

AI 일정 생성은 프롬프트만 믿지 않고, 후보 데이터 자체를 DB 안의 장소로 제한한 뒤 응답을 JSON으로 검증하고, 슬롯/카테고리/예산을 후처리에서 다시 보정하도록 만들었습니다. 이 과정은 30개 오류 응답 변형 테스트와 단위 테스트로 회귀 검증했습니다.
